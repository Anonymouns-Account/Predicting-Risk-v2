# Use of AI-assisted tools

AI-assisted tools were used during code development, debugging, research notebook organization, documentation, and review of diagnostic outputs. The underlying bacterial and weather measurements are from public government datasets, not generated by AI. The study's reported outputs and analysis require independent checking by the author, who is responsible for the research decisions and claims. The repository includes the source code, data, saved predictions and verification files so that results can be audited.
