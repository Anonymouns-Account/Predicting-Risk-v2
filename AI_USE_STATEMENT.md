# Use of AI-assisted tools

AI/LLM tools were used as a support tool during the preparation of this project. They assisted with code debugging, notebook organization, and the organization of reproducibility materials within an anonymous Github. AI was used to improve grammar, punctuation, and formatting. AI tools were not used as a data source, and they did not independently collect data, run final analyses, interpret results, or make research decisions. The student author reviewed, edited, tested, and validated the code, results, figures, and manuscript content. The student author remains fully responsible for the originality, accuracy, analysis, and interpretation presented in this study.
